Bark & Bloom Grooming Co.

A responsive small-business website concept for a fictional dog grooming studio in Los Angeles.

This project was created as a portfolio piece to demonstrate front-end web design, responsive layout, service-based business UX, pricing presentation, and appointment-focused conversion design.

Live Concept

Bark & Bloom Grooming Co. is a fictional brand created for portfolio purposes.

Features

• Responsive HTML and CSS layout
• Mobile-friendly navigation and sections
• Service cards with clear pricing
• Grooming gallery
• About / brand story section
• Pricing table
• Testimonial section
• Appointment request form
• Accessible labels and semantic structure
• Custom visual identity using sage green, cream, and terracotta tones

Built With

• HTML5
• CSS3

Portfolio Focus

This project was designed to show how a service-based local business can present:

• clear service options
• transparent starting prices
• a strong visual brand
• customer trust signals
• mobile usability
• a simple booking path
